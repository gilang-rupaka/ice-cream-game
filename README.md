# Supply Chain Games: Ice Cream

Permainan pengiriman es krim dari gudang dingin ke toko untuk kegiatan Pengabdian kepada Masyarakat (PKM) bidang manajemen logistik di Politeknik Transportasi Darat Bali. Sasaran pesertanya siswa TK sampai SMA.

Mainkan secara online: https://gilang-rupaka.github.io/ice-cream-game/

Aplikasi berjalan di browser tanpa server dan tanpa database. Permainan tersimpan otomatis di browser yang dipakai.
